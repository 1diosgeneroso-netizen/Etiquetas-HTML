102 etiquetas HTML

Catálogo de consulta con numeración secuencial, nombre, descripción, ejemplo de uso y recomendaciones adicionales.

102 etiquetasEjemplos de códigoBuscador integradoDiseño adaptable
Nota: algunas entradas al final son etiquetas obsoletas o no estándar, incluidas con fines históricos y educativos. Se identifican en sus observaciones y no deben usarse en proyectos nuevos. Algunas etiquetas HTML son elementos vacíos y no llevan cierre.

Mostrando 102 de 102 etiquetas.

NúmeroNombre de la etiquetaDescripciónEjemplo de usoElemento adicional
1<a>Define un hipervínculo hacia otra página o recurso.
<a href="https://example.com">Visitar ejemplo</a>
href define el destino; target="_blank" abre otra pestaña.
2<abbr>Marca una abreviatura o sigla.
<abbr title="Universidad Autónoma de Santo Domingo">UASD</abbr>
title puede mostrar el significado completo.
3<address>Incluye información de contacto del autor o propietario.
<address>Contacto: correo@example.com</address>
No se utiliza para cualquier dirección mencionada en el texto.
4<area>Define una zona interactiva dentro de un mapa de imagen.
<area shape="rect" coords="0,0,100,80" href="zona.html" alt="Zona 1">
Se coloca dentro de map y requiere alt.
5<article>Representa contenido independiente, como una noticia.
<article><h2>Noticia</h2><p>Contenido...</p></article>
Puede tener sentido por sí solo.
6<aside>Contiene información complementaria.
<aside><p>Lectura recomendada</p></aside>
Puede servir como barra lateral.
7<audio>Inserta audio reproducible.
<audio controls src="audio.mp3">Audio no compatible</audio>
controls muestra los controles del reproductor.
8<b>Llama la atención sobre texto sin indicar importancia semántica.
<p>Palabra <b>clave</b></p>
Para importancia real, suele preferirse strong.
9<base>Define la URL base de las direcciones relativas.
<base href="https://example.com/">
Se coloca en head.
10<bdi>Aísla texto cuya dirección puede ser diferente.
<bdi>اسم المستخدم</bdi>
Útil con idiomas de derecha a izquierda.
11<bdo>Fuerza la dirección de escritura del texto.
<bdo dir="rtl">Texto</bdo>
dir puede ser rtl o ltr.
12<blockquote>Representa una cita extensa.
<blockquote cite="https://example.com"><p>Una cita.</p></blockquote>
cite puede indicar la fuente.
13<body>Contiene el contenido principal visible de la página.
<body><h1>Hola</h1></body>
Un documento normal tiene un body.
14<br>Inserta un salto de línea.
Primera línea<br>Segunda línea
Es un elemento vacío; no necesita cierre.
15<button>Crea un botón interactivo.
<button type="button">Presionar</button>
Usa type="submit" para enviar formularios.
16<canvas>Crea un área de dibujo manipulable con JavaScript.
<canvas id="lienzo" width="200" height="100">Dibujo</canvas>
El dibujo suele realizarse con Canvas API.
17<caption>Añade un título a una tabla.
<table><caption>Notas finales</caption></table>
Debe estar dentro de table.
18<cite>Marca el título de una obra creativa.
<cite>Don Quijote de la Mancha</cite>
No se usa simplemente para marcar el nombre de una persona.
19<code>Representa un fragmento de código.
<code>console.log("Hola")</code>
Puede combinarse con pre para bloques.
20<col>Define propiedades para una o varias columnas.
<col span="2">
Se coloca dentro de colgroup.
21<colgroup>Agrupa columnas de una tabla.
<colgroup><col span="2"></colgroup>
Se coloca dentro de table.
22<data>Asocia un valor legible por máquina con texto visible.
<data value="123">Producto A</data>
value contiene el valor procesable.
23<datalist>Ofrece sugerencias para un campo de entrada.
<input list="frutas"><datalist id="frutas"><option value="Mango"></datalist>
Se vincula mediante el atributo list.
24<dd>Describe un término en una lista de descripción.
<dl><dt>HTML</dt><dd>Lenguaje de marcado</dd></dl>
Se usa dentro de dl.
25<del>Marca contenido eliminado del documento.
<p><del>RD$500</del> RD$400</p>
Puede incluir cite y datetime.
26<details>Crea un panel que se abre y cierra.
<details><summary>Ver más</summary><p>Detalle</p></details>
summary aporta el encabezado interactivo.
27<dfn>Marca un término que se está definiendo.
<p><dfn>HTML</dfn> es un lenguaje de marcado.</p>
Se usa en el contexto de una definición.
28<dialog>Representa un cuadro de diálogo.
<dialog open>Mensaje informativo</dialog>
JavaScript puede abrirlo con showModal().
29<div>Agrupa contenido en un contenedor genérico.
<div class="tarjeta">Contenido</div>
Úsalo cuando no exista un elemento semántico mejor.
30<dl>Crea una lista de términos y descripciones.
<dl><dt>CSS</dt><dd>Estilos</dd></dl>
Contiene elementos dt y dd.
31<dt>Define un término en una lista de descripción.
<dl><dt>CPU</dt><dd>Procesador</dd></dl>
Se utiliza dentro de dl.
32<em>Marca texto con énfasis.
<p>Es <em>muy</em> importante.</p>
Aporta significado semántico, no solo cursiva.
33<embed>Incrusta un recurso externo compatible.
<embed src="archivo.pdf" type="application/pdf">
La compatibilidad depende del navegador y del recurso.
34<fieldset>Agrupa controles relacionados de un formulario.
<fieldset><legend>Datos</legend><input name="nombre"></fieldset>
legend proporciona el título del grupo.
35<figcaption>Añade una leyenda a una figura.
<figure><img src="foto.jpg" alt="Paisaje"><figcaption>Paisaje</figcaption></figure>
Se coloca dentro de figure.
36<figure>Agrupa contenido independiente como imagen o diagrama.
<figure><img src="grafico.png" alt="Gráfico"><figcaption>Resultados</figcaption></figure>
Puede incluir figcaption.
37<footer>Representa el pie de una página o sección.
<footer><p>© 2026 Mi sitio</p></footer>
Puede incluir autoría o información legal.
38<form>Crea un formulario para recopilar y enviar datos.
<form action="/enviar" method="post"><input name="correo"><button>Enviar</button></form>
action define destino y method el método.
39<h1>Define un encabezado de nivel principal.
<h1>Mi página</h1>
Organiza el contenido por jerarquía.
40<h2>Define un encabezado de segundo nivel.
<h2>Sección principal</h2>
Normalmente divide secciones de h1.
41<h3>Define un encabezado de tercer nivel.
<h3>Subsección</h3>
Debe respetar la jerarquía del contenido.
42<h4>Define un encabezado de cuarto nivel.
<h4>Detalle</h4>
Se utiliza en niveles inferiores de una sección.
43<h5>Define un encabezado de quinto nivel.
<h5>Subtema</h5>
Es un nivel inferior a h4.
44<h6>Define un encabezado de sexto nivel.
<h6>Detalle menor</h6>
Es el nivel de encabezado más bajo.
45<head>Contiene metadatos y enlaces a recursos.
<head><title>Mi página</title></head>
No contiene el contenido principal visible.
46<header>Representa contenido introductorio o encabezado de sección.
<header><h1>Mi sitio</h1></header>
Puede incluir título o navegación.
47<hgroup>Agrupa un encabezado con texto secundario relacionado.
<hgroup><h1>HTML</h1><p>Guía básica</p></hgroup>
Se usa para agrupar título y subtítulo.
48<hr>Representa una separación temática.
<p>Tema uno</p><hr><p>Tema dos</p>
Normalmente se muestra como una línea.
49<html>Es el elemento raíz del documento HTML.
<html lang="es">...</html>
lang identifica el idioma principal.
50<i>Marca texto en una voz alternativa o término técnico.
<p>El término <i>software</i> es común.</p>
No debe usarse solo por decoración.
51<iframe>Inserta otra página dentro de la página actual.
<iframe src="https://example.com" title="Página de ejemplo"></iframe>
Incluye un title descriptivo.
52<img>Inserta una imagen.
<img src="foto.jpg" alt="Persona en un parque">
alt mejora la accesibilidad; es un elemento vacío.
53<input>Crea un control de entrada de formulario.
<input type="email" name="correo" required>
type puede ser text, email, date, checkbox, etc.
54<ins>Marca contenido añadido al documento.
<p>La entrega es el <ins>viernes</ins>.</p>
Puede incluir datetime.
55<kbd>Representa una entrada del usuario por teclado.
<kbd>Ctrl</kbd> + <kbd>S</kbd>
Útil para mostrar teclas y atajos.
56<label>Asocia una descripción con un control de formulario.
<label for="nombre">Nombre</label><input id="nombre">
for debe coincidir con el id del control.
57<legend>Define el título de un grupo fieldset.
<fieldset><legend>Contacto</legend><input type="email"></fieldset>
Ayuda a comprender el grupo de controles.
58<li>Define un elemento de una lista.
<ul><li>Manzana</li></ul>
Se usa dentro de ul, ol o menu.
59<link>Relaciona el documento con un recurso externo.
<link rel="stylesheet" href="estilos.css">
Normalmente se coloca en head.
60<main>Contiene el contenido principal de la página.
<main><h1>Contenido principal</h1></main>
Normalmente hay un solo main visible.
61<map>Define un mapa de imagen con zonas interactivas.
<map name="mapa"><area shape="rect" coords="0,0,80,80" href="zona.html" alt="Zona"></map>
Se asocia a una imagen con usemap.
62<mark>Resalta texto relevante en su contexto.
<p>Busca <mark>HTML</mark>.</p>
El navegador suele mostrar fondo resaltado.
63<menu>Representa una lista de comandos o elementos.
<menu><li><button>Guardar</button></li></menu>
Puede agrupar comandos.
64<meta>Define metadatos como codificación o descripción.
<meta charset="UTF-8">
También se usa para viewport; va en head.
65<meter>Muestra una medida dentro de un rango conocido.
<meter min="0" max="100" value="75">75%</meter>
Para el progreso de una tarea, usa progress.
66<nav>Agrupa enlaces importantes de navegación.
<nav><a href="index.html">Inicio</a> <a href="contacto.html">Contacto</a></nav>
No todos los enlaces deben estar dentro de nav.
67<noscript>Muestra contenido alternativo cuando JavaScript no está disponible.
<noscript>Esta función requiere JavaScript.</noscript>
El contenido depende de la configuración del navegador.
68<object>Incrusta un recurso externo, por ejemplo un PDF.
<object data="documento.pdf" type="application/pdf">Descargar PDF</object>
Puede contener contenido alternativo.
69<ol>Crea una lista ordenada.
<ol><li>Primero</li><li>Segundo</li></ol>
start permite definir el número inicial.
70<optgroup>Agrupa opciones relacionadas de un select.
<select><optgroup label="Frutas"><option>Mango</option></optgroup></select>
label nombra el grupo.
71<option>Define una opción en select o datalist.
<select><option value="rd">República Dominicana</option></select>
value define el valor de la opción.
72<output>Muestra el resultado de un cálculo o acción.
<output name="resultado">10</output>
Puede actualizarse mediante JavaScript.
73<p>Representa un párrafo de texto.
<p>Este es un párrafo.</p>
Puede contener texto y elementos en línea.
74<picture>Permite ofrecer imágenes alternativas según condiciones.
<picture><source media="(max-width:600px)" srcset="movil.jpg"><img src="escritorio.jpg" alt="Paisaje"></picture>
Debe incluir img como alternativa final.
75<pre>Muestra texto preformateado conservando espacios y saltos.
<pre>línea uno
  línea dos</pre>
Útil para bloques de código.
76<progress>Muestra el progreso de una tarea.
<progress value="60" max="100">60%</progress>
Sin value representa progreso indeterminado.
77<q>Marca una cita breve dentro de un párrafo.
<p>Ella dijo: <q>Hola</q>.</p>
El navegador suele añadir comillas.
78<rp>Da paréntesis alternativos si ruby no es compatible.
<ruby>漢 <rp>(</rp><rt>kan</rt><rp>)</rp></ruby>
Se usa junto con ruby y rt.
79<rt>Contiene la anotación o pronunciación de texto ruby.
<ruby>漢<rt>kan</rt></ruby>
Común en anotaciones de pronunciación.
80<ruby>Representa anotaciones de pronunciación.
<ruby>漢<rt>kan</rt></ruby>
Útil especialmente en idiomas de Asia oriental.
81<s>Marca contenido que ya no es exacto o relevante.
<p><s>Precio anterior: RD$500</s></p>
Para una eliminación editorial usa del.
82<samp>Representa la salida de un programa.
<samp>Operación correcta</samp>
Suele mostrarse en fuente monoespaciada.
83<script>Incluye o enlaza código ejecutable, normalmente JavaScript.
<script src="app.js" defer></script>
defer permite analizar HTML antes de ejecutar el archivo.
84<search>Representa una región destinada a búsquedas o filtros.
<search><form><input type="search" placeholder="Buscar"><button>Ir</button></form></search>
Añade significado semántico a una región de búsqueda.
85<section>Agrupa contenido relacionado temáticamente.
<section><h2>Servicios</h2><p>Descripción.</p></section>
Suele tener un encabezado.
86<select>Crea una lista de opciones seleccionables.
<select name="pais"><option>República Dominicana</option></select>
Puede contener option y optgroup.
87<slot>Define un espacio de inserción en un componente web.
<slot name="titulo">Título predeterminado</slot>
Se usa con Web Components y Shadow DOM.
88<small>Representa comentarios secundarios o letra pequeña.
<small>© 2026 Todos los derechos reservados.</small>
No se utiliza solo para reducir el tamaño visual.
89<source>Proporciona recursos alternativos para audio, video o picture.
<video controls><source src="video.mp4" type="video/mp4"></video>
El navegador selecciona un recurso compatible.
90<span>Agrupa texto en línea sin significado propio.
<p>Estado: <span class="activo">Activo</span></p>
Útil para estilos o manipulación con JavaScript.
91<strong>Indica gran importancia del contenido.
<strong>Atención:</strong> revise los datos.
Suele mostrarse en negrita por defecto.
92<style>Incluye reglas CSS dentro del documento.
<style>p { color: navy; }</style>
Normalmente se coloca en head.
93<sub>Muestra texto como subíndice.
H<sub>2</sub>O
Se usa en fórmulas y notación.
94<summary>Define el encabezado visible de details.
<details><summary>Información</summary><p>Detalle</p></details>
Debe ser el primer hijo de details.
95<sup>Muestra texto como superíndice.
2<sup>3</sup> = 8
Se usa en potencias y notas.
96<table>Crea una tabla de datos.
<table><tr><th>Nombre</th></tr><tr><td>Ana</td></tr></table>
Usa tablas para datos, no para maquetar toda la página.
97<tbody>Agrupa las filas del cuerpo de una tabla.
<tbody><tr><td>Dato</td></tr></tbody>
Puede separarse de thead y tfoot.
98<td>Define una celda de datos de una tabla.
<tr><td>Eduard</td><td>Informática</td></tr>
colspan y rowspan pueden abarcar varias celdas.
99<template>Guarda contenido que no se muestra hasta ser utilizado.
<template id="tarjeta"><p>Nueva tarjeta</p></template>
JavaScript puede clonar su contenido.
100<textarea>Crea un campo de texto de varias líneas.
<textarea name="comentario" rows="4"></textarea>
rows define la altura inicial en líneas.
101<tfoot>Agrupa las filas de resumen o pie de tabla.
<tfoot><tr><td>Total</td><td>100</td></tr></tfoot>
Puede contener totales o resúmenes.
102<th>Define una celda de encabezado de tabla.
<th scope="col">Nombre</th>
scope ayuda a relacionar encabezados y celdas.
